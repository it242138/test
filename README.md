# ワイプ・アーケード

JSON の「問題パック」で遊ぶ、ミニゲーム＆クイズ専用の Web アプリです。
**42種類の遊び × 6つの進め方 × ひねり（最大7種類）＝ 1,296 形式**。さらに問題パックの中で「オリジナル形式」を作ると、そのぶん形式がふえます。

問題（中身）とゲーム（遊び方）が分かれているのが特長です。1つの問題がいろいろなゲームに変わるので、**JSON に問題を足すだけで、全部のゲームで遊べる問題がふえます**。

---

## 1. 開き方

| 方法 | やり方 | 問題の読みこみ先 |
|---|---|---|
| かんたん | `index.html` をダブルクリック | `js/packs-bundle.js`（packs フォルダの中身をまとめたもの） |
| おすすめ | `start.bat`（Mac / Linux は `start.sh`）をダブルクリック ※Node.js が必要 | `packs` フォルダの JSON をそのまま読む |

- `start.bat` で開くと、`packs` フォルダに JSON を入れて**ブラウザを再読みこみするだけ**で問題がふえます。
- `index.html` を直接開くときは、JSON を足したあとに `make-bundle.bat`（または `node tools/build-bundle.mjs`）を1回実行してください。
- 画面の「問題パック」から JSON を読みこむ方法なら、どちらの開き方でも、なにも実行せずに追加できます（そのブラウザに保存されます）。
- インターネットがなくても遊べます（文字のフォントだけ、オンラインのときにきれいなものになります）。

## 2. 画面

- **あそぶ**：「きょうの1本」（日がわりのおすすめ形式）、「おまかせ」（ランダム）、ゲームの一覧。ゲームのカードをタップすると、進め方とひねりを選んでスタートできます。
- **形式一覧**：1,296 形式を全部ならべた一覧。なかま・進め方・ひねり・未プレイ・★3じゃないもの などでしぼりこめます。
- **問題パック**：パックのオン／オフ、JSON の読みこみ（ファイル選択・ドラッグ＆ドロップ・はりつけ）、ひな形のダウンロード、パックごとのチェック結果、「このパックだけで遊ぶ」、かんたんエディタ（マイパック）。
- **設定**：音量・画面の色（自動／明るい／暗い）・動き（なしにすると目にやさしい）・紙吹雪の量・振動・記録のリセット。
- **結果**：星（★0〜3）・点数・ベスト更新・最大コンボ・**まちがえた問題のふりかえり**・おすすめの次の形式。

キーボード：選択肢は数字キー、○×や2択は ← →、早押し・ルーレットはスペース、Esc でやめる。

## 4. 問題パック（JSON）の書き方

```json
{
  "id": "my-pack",
  "title": "わたしの問題パック",
  "description": "説明（なくてもOK）",
  "author": "なまえ",
  "items": [
    { "type": "choice", "q": "日本でいちばん高い山は？", "choices": ["富士山", "北岳", "槍ヶ岳", "穂高岳"], "answer": 0, "explain": "3776m。" }
  ],
  "formats": []
}
```

- `id` は英数字と `. - _`（ほかのパックとかぶらないように）。`items` に問題をならべます。
- 画面の「問題パック」→「ひな形をダウンロード」で、**全部の種類の見本が入ったファイル**がもらえます。
- VS Code などのエディタを使うなら、いちばん上に `"$schema": "../schema/pack.schema.json",` と書くと入力の手助けが出ます（packs フォルダに置いたとき）。

### 問題の種類（type）

| type | 書き方 | 決まり |
|---|---|---|
| `choice`（選択） | `{ "q", "choices":[…], "answer":0 }` | 選択肢2〜6こ（40文字まで）。`answer` は正解の番号（1つめが **0**）。`"short"`（16文字まで）を付けると「問題と答えのペア」にも使われる |
| `truefalse`（○×） | `{ "q", "answer":true }` | `true`＝ほんと、`false`＝うそ |
| `number`（数字） | `{ "q", "answer":3776, "unit":"m", "label":"富士山" }` | `min`・`max`・`step` でスライダーのはんいも決められる |
| `year`（年号） | `{ "q", "answer":1600, "label":"関ヶ原の戦い" }` | 整数の西暦 |
| `order`（ならべかえ） | `{ "q", "items":[正しい順に], "values":[…] }` | 3〜8こ（30文字まで）。`values`（年など）は答え合わせのときに出る |
| `pairs`（ペア） | `{ "q", "pairs":[["日本","東京"], …] }` | 3〜8組（左20文字・右24文字まで） |
| `groups`（なかま分け） | `{ "q", "groups":[{ "name":"くだもの", "items":[…] }, …] }` | 2〜4グループ・各2〜8こ（16文字まで）。全部ちがうことばにする |
| `word`（ことば） | `{ "q":"ヒントの問題文", "answer":"バナナ", "hint":"…" }` | 2〜10文字・スペースなし（「文字さがし」は6文字まで） |
| `blank`（穴うめ） | `{ "text":"「[猿] も木から落ちる」", "choices":["猿","犬","猫","鳥"] }` | `[ ]` は1か所だけ。`choices` に正解を入れる |

どの種類にも付けられるもの：`"tags":["宇宙"]`（しぼりこみ用）、`"level":1`（1〜3）、`"explain":"解説"`（300文字まで）、`"source":{ "label":"出典", "url":"https://…" }`、`"id"`。

### 1つの問題が、いろいろなゲームに変わる

| 書いた問題 | 使われるゲームの形 |
|---|---|
| choice | 選択（4択・アクション・ボード系の全部）／○×（「答えは○○」がほんとか）／ペア（`short` があるとき） |
| truefalse | ○×／選択（◯ほんと・✕うそ の2択） |
| year・number | 数（ピタリ賞など）／選択（近い数で選択肢を自動で作る）／○×（「何年？」「何m？」で終わる問題）／**`label` があると**くらべる（どっち？）・年表カード・ならべかえ・ペア |
| order | ならべ／選択（「いちばん最初は？」） |
| pairs | ペア／選択（「○○とペアになるのは？」）／○× |
| groups | なかま／選択（なかまはずれ）／○× |
| word | ことば／選択（ことばが4つ以上あるとき） |
| blank | 選択／○× |

**こつ**：年号や数字には `label`（短い名前）を付けましょう。同じ `unit` のものが4つ以上あると「年表づくり」「れんぞくハイ＆ロー」などで遊べるようになります。

### オリジナル形式（formats）

パックの中で、遊びの種類・進め方・ひねり・しぼりこみを組み合わせた「名前つきの形式」を作れます。形式一覧や、ゲームの説明シートに出てきます。

```json
"formats": [
  { "id": "space-boss", "name": "宇宙ボスバトル", "game": "boss", "flow": "survival", "twist": "dark",
    "description": "宇宙の問題だけで、くらやみの中のボスと戦う",
    "filter": { "tags": ["宇宙"], "level": [1, 2], "thisPackOnly": true } }
]
```

`game` は上の表の id、`flow` は進め方の id、`twist` はひねりの id。`filter` の `thisPackOnly:true` で、このパックの問題だけを使います。

## 5. 問題を追加する3つの方法

1. **packs フォルダに置く**：JSON ファイルを `packs` に入れる。`start.bat` で開いているなら再読みこみするだけ。`index.html` を直接開くなら `make-bundle.bat` を実行。
2. **画面から読みこむ**：「問題パック」画面にドラッグ＆ドロップ、または「ファイルを選ぶ」「はりつけて読みこむ」。このブラウザに保存されます（けすこともできます）。
3. **かんたんエディタ**：「問題パック」画面の下の「問題を作る」。JSON を書かずに、ふつうの入力らんで作れます。作った問題は「マイパック」に入り、「マイパックを JSON で保存」で書き出せます。

まちがいのある問題は、その問題だけが使われず、どこがまちがっているかがパックのカードに表示されます。

## 6. AI で問題パックを作る

### API キーで自動で作る（tools/ai-pack.mjs）

```sh
node tools/ai-pack.mjs --topic "宇宙" --count 50 --level 1 --for "小学生"
```

`packs/ai-○○.json` ができます（Windows は `make-pack-ai.bat` をダブルクリックして、テーマを入れるだけでもOK）。

**API キーはファイルに書かず、環境変数で渡してください**（パックやフォルダを人に配っても、キーがもれません）。

```bat
rem Windows（このウィンドウの中だけ有効）
set GEMINI_API_KEY=ここにキー
node tools\ai-pack.mjs --topic "恐竜"
```
```sh
# Mac / Linux
GEMINI_API_KEY=ここにキー node tools/ai-pack.mjs --topic "恐竜"
```

- `GEMINI_API_KEY`（Google AI Studio）か `ANTHROPIC_API_KEY`（Claude）のどちらか。`AI_PROVIDER=gemini|claude`・`AI_MODEL=モデル名` でも切りかえられます。
- AI の答えは自動でチェックされ、形のまちがった問題は入りません。ただし**内容が正しいかまではわからない**ので、遊ぶ前にざっと読んで確かめてください。

### チャットの AI に頼む（キーなし）

次の文をチャットの AI にはりつけ、テーマを書きかえて送り、返ってきた JSON を「はりつけて読みこむ」に入れます。

```

{ "id":"英数字のid", "title":"パックの名前", "items":[ … ] }
items の種類：
choice    { "type":"choice", "q":"問題", "choices":["正解","まちがい","まちがい","まちがい"], "answer":0, "explain":"解説" }

number    { "type":"number", "q":"〜は何m？", "answer":数, "unit":"m", "label":"20文字までの名前" }
order     { "type":"order", "q":"〜の順にならべよう", "items":["1番目","2番目","3番目","4番目"] }

```

## 7. ニュースワイプの問題を取りこむ

ニュースワイプの `daily` フォルダ（毎日の問題）から、問題パックを作れます。

```sh
node tools/from-newswipe.mjs ../newswipe/daily

```

ニュースの○×・年号・年表ならべ・見出し穴うめ・まちがい見出し・ボス戦の文が、それぞれ○×・年号・ならべかえ・穴うめ・選択に変わります（答えがまだない「未来の予想」は入りません）。同梱の `packs/newswipe-news.json` は 10月14日・15日号から作ったものです。

## 9. ゲームを作る

`js/games/_template.js` をコピーして、`index.html` に `<script>` を1行足すだけで、新しいゲームが「進め方6種類 × ひねり」の形式としてカタログに追加されます。

- `shape` に問題の形（`choice` `tf` `num` `compare` `order` `pairs` `groups` `word` `card`）を書くと、その形に変わった問題が `render(it, done, ctx, box)` に1問ずつ届きます。
- 答えが決まったら `done(正解か, { pts:点数, reveal:'正解は…' })` を1回呼ぶだけ。点数・コンボ・ライフ・時間・記録・結果画面はエンジン（`js/engine.js`）がやります。
- `ctx` の道具：`ctx.keys(fn)`（キー操作）、`ctx.later(fn, ms)`／`ctx.every`／`ctx.loop(dt => …)`（ゲームが終わると自動で止まる）、`ctx.startQ(fn, 秒)`（1問の制限時間）、`ctx.sfx('ok')`（効果音）、`ctx.rules`（進め方・ひねり）、`ctx.reverse()`（あまのじゃく）、`ctx.twistOpts(box)`（ちらり・シャッフル）。
- ボードを最後まで自分で動かすゲームは `kind:'board'` と `mount(area, ctx)` で作れます（`ctx.take()`・`ctx.result(ok)`・`ctx.done()` を使う。クイズビンゴや年表づくりが見本）。
- `solve(ok)` を返しておくと、`index.html?test=1` の自動テスト（`NW.test.solve(true)`）で全形式を動かして確かめられます。

## 10. フォルダの中身

```
index.html            アプリ本体（ダブルクリックで開ける）
start.bat / start.sh  サーバーで開く（packs フォルダを直接読む）
make-bundle.bat       packs フォルダ → js/packs-bundle.js にまとめる
make-pack-ai.bat      AI に問題パックを作ってもらう
css/                  見た目（arcade.css＝画面、games.css＝ゲームと演出）
js/core.js            保存・効果音・演出などの共通の道具
js/art.js             キャラクターの絵（ニュースワイプと同じワイプンたち）
js/engine.js          ゲームエンジン（形式・点数・コンボ・ライフ・時間・記録）
js/packs.js           パックの読みこみと、問題を各ゲームの形に変える部分
js/validate.js        パックのチェック（ブラウザと tools で共通）
js/games/*.js         42種類のゲーム（_template.js はひな形）
js/app.js             画面（ホーム・形式一覧・パック・設定・結果）
js/packs-bundle.js    packs フォルダのまとめ（自動で作られる）
packs/*.json          問題パック（同梱 6 パック・316 問）
schema/               JSON の形（エディタの入力補助用）
tools/                build-bundle・validate・serve・ai-pack・from-newswipe
```

同梱パック：一般常識ミックス／歴史と年号／理科・自然・宇宙／日本と世界の地理／ことば・漢字・英語／ニュースワイプの問題。

## 11. 注意

- 記録・設定・読みこんだパック・マイパックは、**そのブラウザの中だけ**に保存されます（ほかの人には見えません）。ブラウザのデータを消すと消えます。大事なマイパックは JSON で保存しておいてください。
- API キーは環境変数で渡し、ファイルに書かないでください。
- 問題の内容（とくに AI が作ったもの）は、遊ぶ前に確かめてください。
